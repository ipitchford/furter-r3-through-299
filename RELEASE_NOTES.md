# Release notes

Initial unrefereed candidate release.

- Proves Furter's `R(3,n)` for every `1 <= n <= 299` by exact
  computer-assisted certificates.
- Extends the published LPS finite benchmark for the relevant radical window
  from `d < 50` to `d <= 300`.
- Proves a Kummer-theoretic periodic zero band and the resulting obstruction
  to a universal one-fixed-prime GOOD-fibre certificate.
- Publishes the frozen 125-entry Stage 0 evidence manifest, replay scripts,
  controls, root receipt, and external fresh-extraction receipt.
- Publishes a machine-readable Universal `R(3)` Challenge with three
  structural routes and explicit falsifiers.

Universal `R(3)` remains open. This candidate has not been specialist peer
reviewed or independently reconstructed outside the authoring workflow.
